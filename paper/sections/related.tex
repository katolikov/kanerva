\section{Related work}

\paragraph{Memory systems.} Memory layers include OS-style paging by the agent \cite{packer2023memgpt}, LLM-curated fact stores \cite{chhikara2025mem0}, temporal knowledge graphs with bi-temporal edge invalidation \cite{rasmussen2025zep}, linked notes \cite{xu2025amem}, graph retrieval \cite{gutierrez2025hipporag2,edge2024graphrag,guo2024lightrag}, and recursive summary trees \cite{sarthi2024raptor}. Generative Agents scores memories by recency, importance and relevance \cite{park2023generative}. Experience memories such as Reflexion, Voyager, ACE and ReasoningBank keep lessons or skills \cite{shinn2023reflexion,wang2023voyager,zhang2025ace,ouyang2025reasoningbank}. All of these use a write path with LLM calls, a read path with a fixed $k$ or an agent decision, or both. Of these systems, Zep/Graphiti is the one with a mechanism for validity. It is binary and depends on the extractor producing the invalidating edge.

\paragraph{Budgeted selection.} Token-budgeted submodular selection for context is an active preprint line. PACMS applies facility location under a knapsack as a pluggable engine and lists learned relevance as future work \cite{pacms2026}. AdaGReS scores relevance against redundancy \cite{adagres2025}, and PC-SubMax compresses prompts with a regularized objective \cite{pcsubmax2026}. The theory rests on Nemhauser et al.\ \cite{nemhauser1978analysis}, on budgeted maximum coverage \cite{khuller1999budgeted}, on partial enumeration \cite{sviridenko2004note,feldman2023practical}, and on cost-benefit greedy with lazy evaluation \cite{krause2005note,minoux1978accelerated,leskovec2007cost}. MMR \cite{carbonell1998mmr} and DPPs \cite{kulesza2012dpp} target diversity without a budget in tokens.

\paragraph{Learning.} Combinatorial and linear semi-bandits give regret with approximate oracles \cite{chen2013combinatorial,chen2016cmab,kveton2015tight,wen2015efficient}, and linear submodular bandits extend this to diversified retrieval and to knapsacks \cite{yue2011linear,yu2016linear,takemori2020submodular}. Our analysis uses the confidence sets of OFUL \cite{abbasi2011improved}. In agent memory, DeMem proves regret bounds for a $K$-state memory partition \cite{zou2026demem} and MemRL shows Q-value convergence \cite{zhang2026memrl}; RSCB-MC and MERA use bandits to choose agent actions in coding \cite{iscan2026rscb,iscan2026mera}. None of these treats token-budgeted selection of items whose validity changes. On reward signals, self-scored episodes inflate wrong answers \cite{asadolahi2026rewardinflation}, so we use execution signals.

\paragraph{Validity and forgetting.} ACT-R base-level activation models the power law of forgetting \cite{anderson1991reflections,anderson2004integrated}, and it has been applied to LLM memory \cite{honda2025actr}. Staleness is a measured failure: with a budget of two records, models acted on stale records in most episodes of one controlled study \cite{nakayashiki2026stale}, and conflict benchmarks exist for chat \cite{tao2026memconflict}. Consolidation follows complementary learning systems \cite{mcclelland1995why,kumaran2016what}. Rate--distortion views of compaction appear in \cite{colaco2026ratedistortion,zou2026demem,sun2026lam}. Colaco and Lahjouji argue that repeated irreversible summarization degrades end-task error faster than retrieval-backed memory, which agrees with the context collapse reported for ACE \cite{zhang2025ace}, and motivates keeping sources.

\paragraph{Compression and parametric memory.} Text compression such as LLMLingua \cite{jiang2023llmlingua,jiang2023longllmlingua,pan2024llmlingua2} works with closed APIs and is complementary to selection. Gist tokens, AutoCompressors, ICAE, and KV-cache eviction \cite{petrov2025gist,chevalier2023autocompressors,ge2023icae,zhang2023h2o,xiao2023streamingllm,li2024snapkv} and test-time weight updates \cite{sun2020ttt,berges2024memorylayers,behrouz2024titans} need access to model internals that closed APIs do not expose.

\paragraph{Benchmarks.} LoCoMo \cite{maharana2024locomo}, LongMemEval \cite{wu2025longmemeval}, MemoryAgentBench \cite{hu2025memoryagentbench} and BEAM \cite{tavakoli2026beam} cover conversational memory. SWE-ContextBench \cite{zhu2026swecontextbench} and VibeMemBench \cite{vibemembench2026} cover coding experience, MemoryCode covers multi-session coding instructions on synthetic data \cite{rakotonirina2025memorycode}, and ContextBench covers retrieval within a task \cite{li2026contextbench}. None of these, as far as we found, tests repository facts that change between sessions over real history.

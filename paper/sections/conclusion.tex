\section{Conclusion}

Treating agent memory as budgeted selection gives a read path that needs no LLM, and on code its strongest lever turned out to be simple: a calibrated estimate of what each candidate is worth. \conclusionsummary{}

The next step is to make the gate speak on vague prompts without flooding unrelated ones, and to measure end to end whether any of this changes what a coding agent gets done.

\paragraph{Reproducibility.} \texttt{make data \&\& make reproduce} rebuilds the benchmark results, the tests with a real agent are run by hand with the scripts named in \texttt{experiments/}, \texttt{make check} verifies each number in this paper against \texttt{results/*.json}, and the RepoMem manifest pins every repository snapshot.
